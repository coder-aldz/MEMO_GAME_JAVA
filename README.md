# Memory Game (Version 1.0)

Welcome to **Aldz Memory Game**, a fun and engaging memory game built using Java and JavaFX! Test your memory skills, enjoy the gameplay, and challenge yourself to beat your best score.

---

## 🎮 Overview

**Aldz Memory Game** is a simple yet entertaining game where players flip cards and match pairs. The game tracks your progress and lets you enjoy the thrill of pattern recognition. With its clean design and intuitive interface, anyone can jump in and play!

---

## 🛠 Features

- **Interactive Gameplay:** Click on cards to reveal their faces and find matching pairs.
- **JavaFX Interface:** A smooth and responsive user interface for optimal gaming experience.
- **Memory Match Logic:** Handles card flips, checks for matches, and resets mismatched cards.
- **Lightweight Design:** Easy to run and play on any system with JavaFX installed.
